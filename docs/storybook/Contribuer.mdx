# Contribuer

DSaaSFR est une proposition ouverte : un retour d'usage, une question ou un désaccord sur
une interprétation du DSFR sont aussi utiles qu'une pull request.

- **Discuter** : ouvrez un [ticket](https://github.com/theocampbell/DSaasFR/issues) avant
  tout changement de comportement.
- **Comprendre les choix** : les [fiches de décision](https://github.com/theocampbell/DSaasFR/tree/develop/docs/decisions)
  expliquent chaque écart par rapport au DSFR ; elles restent « Proposé » tant qu'elles n'ont
  pas été discutées.
- **Contribuer du code** : suivez le [guide du contributeur](https://github.com/theocampbell/DSaasFR/blob/develop/CONTRIBUTING.md)
  (branche `develop`, commits conventionnels, `pnpm check`, accessibilité vérifiée).
